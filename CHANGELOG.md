# Changelog

## 1.0.0 - 2026-08-15

- Initial release-ready Discord VPS bot project.
- Added welcome embeds, music queue, SQLite auto-setup, temp voice rooms, starboard, XP/levels, achievements, stats, fun commands, and moderation logging.
- Added YouTube music hardening with local audio caching, yt-dlp fallback profiles, optional cookies, and optional JavaScript challenge settings.
- Pinned release baseline to `yt-dlp[default]>=2026.7.4`.
- Added systemd service sample and GitHub Actions syntax check.
